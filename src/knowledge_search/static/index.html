                What this line does
                
            Every passage is embedded under a header with the document title and section heading.
                  This adds one more line describing the whole document, so a passage that never names its subject
                  (“set the revision with --to-revision=2”) is still found for “roll back a Deployment”. The line is the
                  document's own description if it has one, else the local model's summary (when installed), else its
                  first paragraph; “Take that line from” can limit it to one of these. Measured on 623 Kubernetes pages at 300 characters (right page first, 56 questions):
                  with the authors' descriptions 94.6% → 98.2% (100% with the MiniLM reranker); without descriptions the
                  first paragraph did not help (96.4% → 96.4%), a Gemma 4 E2B summary did (98.2%). Changing it, or where the line comes from, re-indexes. A new summary length rewrites every summary.
