        Search & indexing settings

        Embedding model

        Larger models retrieve more accurately but index and answer more slowly on CPU. Changing the model requires reindexing every document (done in the background; search keeps working on the old index for keyword matches meanwhile).

        Chunking

        Smaller chunks give more precise passages; larger chunks keep more context. Overlap repeats the end of one chunk at the start of the next so sentences at a boundary are not lost.

        Every passage is always embedded in full, under a header with the document title and section heading. This adds one more header line describing the whole document (the same line on all its passages), so a passage that never names its subject — "set the revision with --to-revision=2" — is still found for "roll back a Deployment". The line is the document's own description if it has one, else the summary written by the local language model (when installed), else the document's first paragraph, cut to this many characters. Measured on 623 Kubernetes pages at 300 characters (right page first, 56 questions): with the authors' descriptions 94.6% → 98.2% (100% with the MiniLM reranker); without descriptions, the first paragraph did not help (96.4% → 96.4%), a summary by Gemma 4 E2B did (98.2%). Changing it requires reindexing.

        Reranker (offline cross-encoder)
        Linked documents

        For questions like “who owns the services the Orders Service depends on”: results also include passages from pages that link to or from the page you name (Markdown links, [[wiki links]], front-matter relations such as depends_on). Up to half of the results come from linked pages; only pages you may read are followed.

        Summaries by a local language model (optional)

        When setup installed a local language model (setup --summaries), it writes a two-sentence summary, up to six topics and — only when a document's own title is vague — a clearer title, one document at a time while no files are waiting to be indexed. Nothing leaves this computer. Results show them labelled as written by the model; they are never used as evidence. With “Add a line about the whole document” on, a document without its own description is re-indexed once so that line becomes the model's summary. Progress: Index status tab.

        Advanced: evidence thresholds

        Tuned on labelled validation queries. Raising them makes the system abstain more often (fewer false answers); lowering them answers more often. Re-run the evaluation after changing the model.
