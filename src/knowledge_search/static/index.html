        Embedding model
        
              
        Larger models retrieve more accurately but index and answer more slowly on CPU. Changing the model
                re-indexes every document in the background; keyword search keeps working meanwhile.
        
            
        
            
        
              
              
        
              
        Models on this computer
                
        
            
        
          
        
          
        
            
        
              
        Passages
        
              
        Smaller passages are more precise; larger ones keep more context. Overlap repeats the end of one
                passage at the start of the next so sentences at a boundary are not lost.
        
            
        
            
        
              
              
              
              
              
        
                What this line does, and what it measured
                
        Every passage is embedded under a header with the document title and section heading.
                  This adds one more line describing the whole document, so a passage that never names its subject
                  (“set the revision with --to-revision=2”) is still found for “roll back a Deployment”. The line is the
                  document's own description if it has one, else the local model's summary (when installed), else its
                  first paragraph. Measured on 623 Kubernetes pages at 300 characters (right page first, 56 questions):
                  with the authors' descriptions 94.6% → 98.2% (100% with the MiniLM reranker); without descriptions the
                  first paragraph did not help (96.4% → 96.4%), a Gemma 4 E2B summary did (98.2%). Changing it re-indexes.
        
              
        
            
        
          
        
          
        
            
        
              
        Reranker
        
              
        An offline cross-encoder reads the top candidates against the question, reorders them and judges
                whether they are evidence.
        
            
        
            
        
              
              
              
        Models on this computer
                
        
              
            
        
          
        
          
        
            
        
              
        Linked documents
        
              
        For questions such as “who owns the services the Orders Service depends on”: results also include
                pages that link to or from the page you name. Only pages you may read are followed.
        
            
        
            
        
              
              
        Markdown links, [[wiki links]] and front-matter relations such as depends_on. Up to half
                of the results come from linked pages.
        
            
        
          
        
          
        
            
        
              
        Local language model
        
              
        Optional, installed with setup --summaries. Nothing leaves this computer. What it writes is
                labelled as the model's and never used as evidence. Progress is on Index status.
        
            
        
            
        
              
              
              
        
              
        Models on this computer
                
        
              
              
        A two-sentence summary, a document type (runbook, how-to, policy, design, …), up to six
                topics that reuse the names already common in the collection and, only when a document's own title is vague,
                a clearer title; one document at a time, each as soon as it is indexed, at low priority so indexing and search come first. Outside its hours the
                model is stopped and its memory freed. With the line about the
                whole document on, a document without its own description is re-indexed once to use the summary.
        
            
        
          
        
          
        
            
        
              
        Evidence thresholds
        
              
        Tuned on labelled questions. Raising them makes search abstain more often (fewer false answers);
                lowering them answers more often. Re-run the evaluation after changing the model.
