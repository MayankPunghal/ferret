testing. It is not company data and results on it do **not** validate quality on a real corpus.

Collections and intended permissions (as set up by `eval/run_eval.py` and the tests):

| Collection    | Readable by groups | Contents |
|---------------|--------------------|----------|
| `engineering` | `staff`, `hr`      | runbooks, API reference, error codes, postmortem (PDF), config |

| `hr`          | `hr` only          | confidential HR policies (parental leave, compensation bands) |

near-miss subjects (software refunds vs hardware, payments on-call vs data-platform on-call),
identifier look-alikes (`ERR-PAY-4012` exists, `ERR-PAY-4013` does not), and restricted HR content.
